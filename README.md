# Таймер активности

Небольшое терминальное приложение для учёта времени в четырёх состояниях:

- лежание;
- сидение;
- стояние;
- полусидя.

Также приложение считает время, когда учёт не был включён, и показывает
статистику по локальным календарным дням. На главном экране живёт текстовый
кот: его поза и настроение меняются вместе с выбранным состоянием.
Отдельная отметка «Попил» запоминает время последнего питья и позволяет считать
количество отметок за каждый день, не прерывая выбранное состояние.
В дневной статистике состояния и события воды разнесены по двум отдельным
шкалам. В каждом часе четыре 15-минутные клетки. На шкале состояний цвет и
фигура показывают позу, занимавшую большую часть четверти часа. На шкале воды
`■` означает отметку в этой четверти часа, `□` — её отсутствие.
В просторном окне приложение автоматически показывает крупные сцены; в
стандартном терминале переключается на компактные варианты без обрезания.
Высота области с котом фиксирована по самому высокому рисунку выбранного
размера, поэтому нижнее управление не прыгает при смене состояния. Каждая
плашка показывает накопленное за сегодня время и пропорциональную полоску;
цвет совпадает с цветом состояния в статистике, а текущая плашка дополнительно
выделяется инверсией.

Большие позы — это ручные работы из коллекции Christopher Johnson, а не
результат генератора. Подписи художников сохранены в самих рисунках:

- лежащий кот — Felix Lee ([источник](https://old.asciiart.website/index.php?art=animals%2Fcats));
- сидящий кот — Sebastian Stöcker, подпись `SSt` ([источник](https://asciiart.website/art/6707));
- идущий кот — Blazej Kozlowski, подпись `[bug]` ([источник](https://asciiart.website/art/4761)).
- кот для состояния «Полусидя» — Joan Stark, подпись `jgs` ([источник](https://asciiart.website/art/329)).
- кот для выключенного режима — Felix Lee в большом окне и Joan Stark (`jgs`)
  в компактном ([источник](https://old.asciiart.website/index.php?art=animals%2Fcats)).

## Запуск

Нужны Linux/macOS, терминал с поддержкой UTF-8 и Python 3.10 или новее.
Внешних Python-пакетов нет.

```bash
cd /home/vladyslav-goncharuk/Documents/Projects/tasks/activity_timer/dev/activity-timer
python3 -m activity_timer
```

Данные сохраняются в
`~/.local/share/activity-timer/activity.sqlite3`.

## Управление

- `1` — лежание;
- `2` — полусидя;
- `3` — сидение;
- `4` — стояние;
- `5` — отметить, что попил;
- `Enter` — перейти к следующему состоянию по кругу;
- `Tab` — открыть или закрыть статистику по дням;
- `←`/`↓` и `→`/`↑` — перейти к более ранним/поздним дням в статистике;
- `Esc` — вернуться из статистики или сохранить состояние и выйти.

После запуска нужно выбрать текущее состояние. Промежуток между предыдущим
выходом и новым выбором будет отмечен как «Приложение не включено». Время до
самого первого запуска неизвестно и в статистику не добавляется.

Приложение сохраняет контрольную отметку каждую секунду. После аварийного
закрытия активное состояние заканчивается на последней такой отметке, а
последующее время считается временем выключенного приложения.
В полночь экранный таймер начинается с нуля, а продолжение текущего состояния
учитывается уже в статистике нового календарного дня.
